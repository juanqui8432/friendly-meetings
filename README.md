# Friendly Meetings

Una agenda visual y liviana para organizar conversaciones de equipo sin perder el foco.

## Qué incluye

- Agenda filtrable por hoy, mañana o todas las reuniones.
- Búsqueda por título, lugar o tipo de reunión.
- Alta de nuevas reuniones desde un modal.
- Marcado de reuniones completadas.
- Resumen de tiempo en foco y personas frecuentes.
- Diseño responsive para escritorio y móvil.

## Ejecutar localmente

Requiere Node.js 18 o superior.

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
```

## Subir a GitHub

Creá un repositorio vacío en GitHub y ejecutá desde esta carpeta:

```bash
git init
git add .
git commit -m "Initial Friendly Meetings app"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git
git push -u origin main
```

No incluye backend ni credenciales: es una base frontend lista para extender.
