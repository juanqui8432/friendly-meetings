# Friendly Meetings

Una agenda visual y liviana para organizar conversaciones de equipo sin perder el foco.

Repositorio: https://github.com/juanqui8432/friendly-meetings

## Qué incluye

- Agenda filtrable por hoy, mañana o todas las reuniones.
- Búsqueda por título, lugar o tipo de reunión.
- Alta de nuevas reuniones desde un modal.
- Marcado de reuniones completadas.
- Resumen de tiempo en foco y personas frecuentes.
- Diseño responsive para escritorio y móvil.

## Ejecutar localmente

Requiere Node.js 18 o superior.

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
```
